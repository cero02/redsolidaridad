# 0001 — Rojo para sincronizar el código con Studio

**Estado:** Aceptado (2026-11-03)

## Contexto
Queremos editar Luau con git, revisión de código, lint y formato automáticos.
Roblox Studio no funciona en Linux, donde trabaja el asistente.

## Decisión
- Usar **Rojo 7.7.1**. El código vive en archivos `.luau`; `default.project.json` define
  dónde se coloca cada carpeta dentro del juego.
- Flujo: cambios en git → `git pull` en el PC del equipo → `rojo serve` → plugin de Rojo
  en Studio → probar.
- Los mapas, modelos y escenarios se construyen en Studio y se guardan en el place.
  Solo el código pasa por Rojo, por ahora.

## Consecuencias
- El asistente puede escribir, formatear, revisar y compilar (`rojo build`), pero no hacer
  pruebas de juego: cada etapa necesita una prueba manual en Studio.
- El plugin de Rojo en Studio debe ser de la misma versión principal que la CLI (7.x).
